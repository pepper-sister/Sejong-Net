# 🎓 Sejong Net 프로젝트

> React와 Kako Map API를 활용하여 세종대학교 정보를 쉽게 확인할 수 있는 웹 서비스<br/>
> 학교 서버시간, 홈페이지, 편의시설 등 다양한 정보를 제공

## 📷 프로젝트 소개

### 🏠 홈

<img width="600" alt="홈" src="https://github.com/user-attachments/assets/aa59b027-85e9-4118-afa6-730b032cab41" />

- **학교 서버시간 제공**: 세종대학교의 현재 서버 시간을 사용자에게 표시
- **홈페이지 정보 제공**: 주요 학교 관련 홈페이지와 바로가기 버튼 제공

---

### 📑 모든 홈페이지

<img width="600" alt="모든 홈페이지" src="https://github.com/user-attachments/assets/be03674b-b533-453d-a1fc-e636265aed87" />

- **학교 관련 사이트**: 세종대학교 관련 사이트 정보 제공
- **사이트 이동**: 관련 사이트로 바로가기 버튼 제공

---

### 🏪 편의시설

<img width="600" alt="편의시설" src="https://github.com/user-attachments/assets/b6a4e4c1-45cd-4689-94af-97b66b523c1f" />

- **Kakao Map API 활용**: 학교 내부 프린터, ATM, 편의점 위치 표시
- **상세 정보 제공**: 각 마커 클릭 시 위치 추가 정보 표시

---

### 🛠️ 기술 스택

- **HTML/CSS**: Flexbox, Grid 기반 레이아웃, 스타일링
- **JavaScript**: 이벤트 처리, API 통신
- **React.js**: UI 구성, 컴포넌트 기반 구조, 상태 관리
